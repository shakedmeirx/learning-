## 15. CE CERTIFICATION PROTOCOL

### Why It Matters
Israel aligns with EU consumer electronics standards. CE-marked items enter customs without friction. Non-CE electrical items can be rejected.

### The Problem
Many AliExpress sellers display a CE logo in product photos without having documentation. A logo sticker is not a CE certificate.

### 4-Step Verification Process

**Step 1 — Request from supplier via AliExpress chat:**
> "Hello, I need to ship this product to Israel/EU. Can you provide the CE certificate and Declaration of Conformity (DoC) as PDF files? My customers require this documentation."

**Step 2 — Validate the PDF received:**
- Contains: product name, model number, manufacturer address, notified body number, date
- Model number on certificate matches product listing
- Looks like an official document, not a one-page branded flyer

**Step 3 — Reject if supplier cannot provide PDF:**
- Do not list an electrical item without CE documentation
- Find another supplier

**Step 4 — Request test report (optional but strong):**
- IEC 62368-1 (audio/video/IT) or IEC 60335 (household appliances)
- Most budget suppliers cannot provide this — accept DoC only if test report unavailable

### Items Requiring CE Verification Before Listing
1. Electric nail drill (any model)
2. UV/LED nail lamp (any model)

### Items NOT Requiring CE
Manual tools (files, buffers, nippers, pushers, dust brushes, stamping plates, practice tips, storage cases, mats) — not electrical, no CE required.

## 17. CRITICAL CONSTRAINTS (DO NOT SKIP)

### Products NEVER to Stock (Shipping Prohibition)
These products CANNOT be shipped via standard ePacket/air freight from China:

| Product | Why Banned | UN Classification |
|---------|-----------|-------------------|
| Nail polish | Flammable liquid | UN1266, Class 3 |
| Gel polish | Flammable liquid | UN1266, Class 3 |
| Nail polish remover | Flammable liquid | UN1325/UN1863 |
| Acetone | Highly flammable | UN1090, Class 3 |
| Nail glue | Flammable liquid | UN3269 |
| Primer / base coat / top coat | Flammable | UN1263 |
| Cuticle oil | May be regulated | Verify per product |
| Any liquid/chemical product | Cosmetic regulation | Check before adding |

**The competitive moat:** Many naive competitors list gel kits without realizing this restriction. Your tools-only strategy is legally clean and operationally simpler.

### Israel VAT Threshold
- Products under **$150 USD**: zero customs duty at Israeli customs
- Products over $150 USD: 17% VAT applies
- Keep all kits under **$75 USD** as safety buffer (not $150) to account for currency fluctuation
- Kit 3 at ₪549–599 (~$148–162) is near the threshold — use ₪549 ($148) as the safe ceiling

### EU Type C Plug Requirement
All electrical items MUST specify EU Type C (Schuko) plug compatibility. Israel uses the same outlets as Europe. US plugs (Type A/B) will not work without an adapter.
