## TRACKING SETUP

### Required Before Launch

| Platform | Client-Side | Priority |
|---------|------------|---------|
| Meta Pixel | Standard Events: ViewContent, AddToCart, Purchase | P1 - must have |
| Meta CAPI | Server-side events via Shopify integration | P1 - strongly recommended |
| TikTok Pixel | Standard Events: ViewContent, AddToCart, Purchase | P2 - launch with |

**Shopify setup:**
1. Install Meta Pixel via Shopify Admin → Preferences → Facebook
2. Enable CAPI (Conversions API) — Shopify has built-in toggle
3. Install TikTok Pixel via TikTok Shopify app
4. Test all pixel events with Meta Pixel Helper Chrome extension

**Key conversion events to track:**
- `ViewContent` (product page view)
- `AddToCart`
- `InitiateCheckout`
- `Purchase` (most critical — this trains Meta's algorithm)

**Target EMQ Score:** 7.0+ by Month 2 (requires matching email/phone data via CAPI for Israeli buyers)

## COMMON PITFALLS TO AVOID

1. **Launching without Pixel + CAPI** — Meta cannot optimize without purchase data
2. **Launching with only 1 creative** — algorithm needs 3–5 assets to test
3. **Manual targeting instead of Advantage+** — A+ beats manual by 32% lower CPA in beauty
4. **Hebrew copy translated from English** — sounds unnatural; write in Hebrew first
5. **Including "CE certification" claim without the actual document** — if challenged by Meta ad review, you need proof
6. **Ignoring creative fatigue** — refresh creatives every 3–4 weeks minimum
7. **Setting ROAS goal too early** — Month 1 is learning phase; don't set ROAS goal until 30+ purchases
8. **Not tracking NIS vs USD** — all Israeli campaigns should be budgeted in NIS to avoid currency fluctuation
